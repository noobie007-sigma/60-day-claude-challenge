# Day 36 – Cognitive Pattern Explorer

## Objective

Built an interactive psychology-inspired educational web application that helps users explore different thinking tendencies through scenario-based activities. The application focuses on self-reflection and learning without making any clinical assessments.

## Features Implemented

* Responsive single-page HTML application
* Calm Mode and Stress Mode
* Interactive decision-making scenarios
* Drag-and-drop priority ranking
* Thinking sequence timeline activity
* Personalized Reflection Journal
* Thinking tendency percentage breakdown
* Progress tracking
* Keyboard accessibility
* Smooth animations
* Fully offline functionality using HTML, CSS, and Vanilla JavaScript

## Prompt Template
```
Create a single-file offline web app called 'Cognitive Pattern Explorer' using only HTML, CSS, and vanilla JavaScript (no frameworks). Combine HTML, CSS, and JS into one responsive file.

Purpose:
Build a psychology-inspired self-reflection experience that explores thinking patterns through interactive scenarios. It must feel calm, game-like, and exploratory rather than like a test.

This is educational only. Never diagnose or clinically assess mental health. Use reflective language ('you often...', 'this suggests...') instead of absolute labels.

Thinking Tendencies:
- Analytical Thinker
- Emotional Intuitive
- Overthinking Loop Style
- Action-First Decision Maker
- Balanced Reflective Thinker

Flow:
1. Start Screen with Calm/Stress Mode.
2. Chapter 1 – Discover Your Thinking Style.
3. Chapter 2 – Choose Your Priorities using draggable cards.
4. Chapter 3 – Map Your Thinking using draggable timelines.
5. Final Reflection Journal with personalized insights and percentage breakdown.

Design:
- Calm modern aesthetic.
- Smooth transitions.
- Progress indicators.
- Responsive layout.
- Ambient animations.
- Keyboard accessibility.
- Reduced motion support.

Technical Requirements:
- Single HTML file.
- Vanilla JavaScript only.
- Native drag-and-drop with touch fallback.
- Works completely offline.
- Store all scenarios as JavaScript objects.
- Reuse drag-and-drop components.
- Verify there are no syntax errors, scoring works, progress tracking works, and the layout is responsive.

Return only one complete HTML file.
```


## Key Learnings

* Interactive scenarios create a more engaging learning experience than traditional questionnaires.
* Different contexts can influence decision-making patterns and priorities.
* Reusable drag-and-drop components simplify development and improve maintainability.
* Personalized feedback enhances user engagement while maintaining an educational focus.
* Offline-first applications can still deliver rich interactive experiences using only web fundamentals.


## Outcome

Successfully developed a complete offline educational web application that demonstrates how AI can assist in creating interactive learning experiences focused on reflection, decision-making, and user engagement.
